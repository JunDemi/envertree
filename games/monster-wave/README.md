# 몬스터웨이브 (Monster Wave)

사방에서 몰려오는 몬스터를 처치하며 버티는 탑다운 웨이브 서바이벌 슈팅.
빠르게 연속 처치(콤보)하면 새 무기가 열리고, 더 긴 콤보를 이으면 무기가 강해진다.

| 항목 | 값 |
| --- | --- |
| slug / 주소 | `monster-wave` / `/games/monster-wave` |
| 해상도 | 960 × 640 (3:2, Phaser Scale FIT으로 iframe에 맞춤) |
| 기술 | Phaser 4.2, Vite 8, TypeScript 7 |
| 아트/사운드 | 외부 파일 없음. 그래픽은 Phaser Graphics, 효과음은 Web Audio로 코드에서 생성 |

모든 이름, 캐릭터, 그래픽, 소리는 오리지널이다.
실제 에셋으로 바꿀 때의 목록과 규격(HD, 2배 제작)은 [Assets.md](Assets.md)에 있다.

## 1. 조작

| 입력 | 동작 |
| --- | --- |
| `W A S D` | 이동 (8방향, 대각선도 같은 속도) |
| 마우스 | 조준 |
| 마우스 왼쪽 | 사격 / 설치 / 투척 (누르고 있으면 연사) |
| `1`~`9`, 휠, `Q`/`E` | 무기 교체 (휠·Q/E는 탄약이 빈 무기를 건너뜀) |
| `ESC` / `P` | 일시정지 (iframe이 포커스를 잃어도 자동 일시정지) |
| `M` | 소리 켜기/끄기 (저장됨) |
| 일시정지 중 `T` | 타이틀로 |

키 매핑은 [`src/config/controls.ts`](src/config/controls.ts) 한 곳에서 바꾼다.

## 2. 규칙 요약

- 아레나 중앙에서 시작. 몬스터는 네 변의 스폰 지점(플레이어 화면 밖)에서 나와 쫓아온다.
- 웨이브의 몬스터를 모두 처치하면 휴식(카운트다운) 후 다음 웨이브. 웨이브가 오를수록 수·종류·체력·속도가 늘어난다.
- 몬스터와 닿거나 화염구에 맞으면 피해 + 넉백 + 짧은 무적. 체력 0이면 게임오버.
- **콤보**: 처치마다 +1, 마지막 처치 후 2초 안에 다음 처치가 없으면 0. 점수 = 기본 점수 × 콤보 배율.
- **무기 해금**: 콤보가 무기의 해금 값에 처음 도달하면 열림 (5 기관단총 → 10 샷건 → 15 바리케이드 → 20 폭발 드럼통 → 30 수류탄 → 40 로켓).
- **무기 레벨업** (해금 우선): **모든 무기를 연 다음부터**, 콤보가 무기의 **해금 값 × 4**에 도달하면 그 무기가 Lv.2, Lv.3 (탄약 가득, **콤보는 0으로 초기화**). 권총은 해당 없음.
  - 레벨업 콤보: 기관단총 20, 샷건 40, 바리케이드 60, 폭발 드럼통 80, 수류탄 120, 로켓 160. 모든 무기가 열리면 무기 슬롯에 `↑20`처럼 표시된다.
  - 모든 무기가 열리기 전에는 레벨업도 콤보 초기화도 없다. (초기화 때문에 콤보 30·40에 닿지 못해 수류탄·로켓을 못 여는 일을 막기 위해)
- 처치 시 확률로 탄약 상자(열린 무기 모두 충전) / 회복 아이템이 떨어진다.
- 폭발은 자기 자신도 약하게 피해를 입는다 (`combat.ts`의 `selfExplosionDamage`로 끄기).

## 4. 코드 구조

```
src/
├── main.ts                 Phaser.Game 생성, 효과음 초기화
├── config/                 ★ 모든 수치 (게임 코드에 숫자를 하드코딩하지 않는다)
├── assets/                 텍스처 키(keys.ts)와 코드로 그리는 프로토타입 텍스처(textures.ts)
├── scenes/                 Boot → Title → Game + UI(HUD, 겹쳐 실행) → GameOver
├── entities/               Player, Monster(+MonsterManager: 풀/이동/분리), Items(드랍)
├── combat/                 투사체 풀(Bullets), 수류탄, 무기 슬롯/탄약/레벨(WeaponController)
├── systems/                WaveManager, Combo, DebugTools
├── world/                  Grid(벽/설치물 격자), Arena(벽 그림·충돌), FlowField, Placeables,
│                           SpatialHash, 격자 충돌(collide), 시야(los), 스폰 지점(spawn)
├── view/depth.ts           3/4 시점: 발밑 기준 배치, depth 정렬, 그림자
├── effects/                파편/폭발/떠오르는 글자, 피해 숫자
├── audio/Sfx.ts            Web Audio 합성 효과음, 음소거
├── input/                  입력 소스 인터페이스 + 키보드·마우스 구현 (플레이어와 분리)
├── portal.ts               game-sdk 호출 래퍼 (ready / gameStart / gameOver({score, wave}))
├── storage.ts              localStorage 래퍼 (최고 점수, 음소거; try/catch)
└── events.ts               GameScene → HUD 이벤트 이름
```

### 핵심 설계

- **3/4 시점**: 게임 로직(위치, 충돌, 조준)은 평면 탑다운 좌표. 그림만 발자국 위로 키만큼 솟게 그리고, 매 프레임 depth = 발밑 y. 플레이어를 가리는 벽·설치물은 반투명 처리.
- **몬스터 추적**: 아레나 격자에 플레이어 기준 플로우 필드(다익스트라)를 0.3초마다(또는 플레이어가 칸을 옮기거나 설치물이 바뀌면) 다시 계산. 몬스터는 자기 칸의 방향만 읽으므로 수백 마리도 가볍다. 설치물 칸은 "지나갈 수 있지만 비용이 큰 칸"이라 몬스터가 돌아가거나 부수고 온다.
- **물리**: 플레이어만 Arcade Physics(벽 충돌). 몬스터·총알은 직접 계산(격자 충돌, 공간 해시)해서 가볍게 유지.
- **풀링**: 몬스터, 투사체(총알/화염구/로켓), 수류탄, 아이템, 피해 숫자는 재사용. 파티클은 Phaser 이미터가 재사용.
- **입력 분리**: 플레이어는 `PlayerInput`(이동 방향, 조준점, 사격, 무기 선택)만 받는다. 2인용이나 터치는 `InputSource` 구현을 추가하면 된다.

## 6. 몬스터 추가하는 법

예: 빠르게 돌진하는 "차저"를 추가한다.

1. `src/config/monsters.ts`
   - `MonsterId`에 `"charger"`를 추가한다.
   - `monsters`에 항목을 추가한다 (체력, 속도, 접촉 피해, 넉백 저항, 점수, 발자국 크기, 높이, 색).
   - 원거리 공격을 하게 하려면 `ranged`를 넣는다 (임프 참고). 시야 확인, 멈춰서 쏘기, 화염구 아군 피해는 공통 코드가 처리한다.
2. `src/config/waves.ts`의 `composition`에 `{ monster: "charger", fromWave: 7, weight: 2 }`처럼 추가한다.
3. 끝. 텍스처는 BootScene이 `monsters`를 돌며 상자 모양으로 자동 생성하고(`assets/textures.ts`의 `bakeMonster`), 타이틀 화면 캐릭터 소개에도 자동으로 들어간다.
   - 실제 스프라이트로 바꿀 때는 `monsterTexture("charger")` 키로 이미지를 로드하면 된다.
   - 타이틀 소개 줄은 5종까지 보기 좋게 배치되어 있다. 더 늘리면 `TitleScene`의 `gap`을 줄인다.
4. 돌진처럼 **새로운 행동**이 필요하면 `MonsterManager.update`의 이동 계산에 분기를 추가하고, 필요한 수치는 `MonsterDef`에 선택 필드로 추가한다.

## 7. 무기 추가하는 법

무기는 네 종류(`kind`) 중 하나다: `gun`(총알), `placeable`(설치), `thrown`(투척), `rocket`(직선 폭발).

1. `src/config/weapons.ts`
   - `WeaponId`에 이름을 추가한다.
   - `weapons` 배열의 원하는 위치에 항목을 넣는다. **배열 순서가 슬롯 번호(1~9키)와 해금 순서**다. 슬롯은 최대 9개.
   - `unlockCombo`(해금 콤보), 탄약(`maxAmmo`, `startAmmo`, `ammoPerPickup`), 종류별 수치를 채운다.
     레벨업 콤보는 `unlockCombo × levelUpComboMultiplier`로 자동 계산된다.
2. 효과음: `src/audio/Sfx.ts`의 `play()` switch에 새 무기 id의 소리를 추가한다. 없으면 소리 없이 동작한다.
3. HUD 슬롯, 해금 알림, 레벨업, 탄약 상자 충전은 자동으로 적용된다.
4. 기존 네 종류로 표현할 수 없는 무기(예: 화염방사기)는 `WeaponDef`에 새 `kind`를 추가하고, `WeaponController.tryFire`와 `applyLevel`, `GameScene`의 `WeaponHandlers` 구현에 분기를 추가한다.

## 8. 아레나 바꾸는 법

`src/config/arena.ts`의 `obstacles`에 `{ col, row, w, h }`(칸 단위 사각형)를 추가/삭제한다. 바깥 테두리 벽은 자동이다.
스폰 지점(`spawnPoints`)이 장애물에 막히면 그 지점은 자동으로 제외된다.

## 9. 디버그 도구

켜기: 주소에 `?debug`를 붙이거나 게임 중 **F2** (포털 iframe 안에서도 가능).
`?debug&wave=8`처럼 시작 웨이브를 지정하면 그 웨이브부터, 모든 무기가 열린 상태로 시작한다.

| 키 | 기능 |
| --- | --- |
| `F2` | 디버그 켜기/끄기 (켜면 화면 왼쪽 위에 패널) |
| `I` | 무적 |
| `N` / `Shift+N` | 다음 웨이브 / 5웨이브 건너뛰기 |
| `U` | 모든 무기 해금 + 탄약 가득 |
| `K` | 그런트 50마리 (성능 확인) |
| `F` | 플로우 필드 화살표 표시 |
| `C` | 충돌 박스 (플레이어·몬스터 발자국, 설치물, 임프 사거리) |

- FPS는 패널에 항상 표시된다.
- 디버그를 한 번이라도 켠 판은 **최고 점수에 기록되지 않는다.**
- `?debug`일 때만 `window.__MW__`로 Phaser 게임 객체가 노출된다 (콘솔/자동 테스트용).

## 10. 밸런스 메모 (Phase 6 분석)

웨이브당 몬스터 수: 12 + 6 × (웨이브 − 1) (처음 안의 1.5배). 동시 생존은 최대 80마리이고 나머지는 대기열에서 차례로 나온다.
무기 DPS는 60fps에서 프레임 단위 발사를 반영한 값 (권총 42, 기관단총 70, 샷건 근거리 97).

| 웨이브 | 몬스터 | 기대 구성 (그런트/러너/브루트/임프) | 총 체력 | 권총만 처치 | 기관단총 | 스폰 완료 |
| --- | --- | --- | --- | --- | --- | --- |
| 1 | 12 | 12 / 0 / 0 / 0 | 360 | 9초 | 5초 | 8.4초 |
| 3 | 24 | 14.7 / 9.3 / 0 / 0 | 662 | 16초 | 9초 | 14.9초 |
| 4 | 30 | 20 / 10 / 0 / 0 | 918 | 22초 | 13초 | 17.4초 |
| **5** | 36 | 17.8 / 8.9 / 3.8 / 5.6 | **1,959** | 46초 | 28초 | 19.4초 |
| 10 | 66 | 36.7 / 18.3 / 3.7 / 7.3 | 3,847 | 91초 | 55초 | 22.4초 |
| 15 | 96 | 53.3 / 26.7 / 5.3 / 10.7 | 6,897 | 163초 | 99초 | 17.3초 |

브루트 처치에 필요한 권총 탄수: 웨이브 1에서 14발(4.0초) → 웨이브 15에서 29발(8.2초).

### 조정 후보 (검토했지만 적용하지 않음)

| # | 수치 | 현재 → 후보 | 이유 |
| --- | --- | --- | --- |
| 1 | 웨이브 5 첫 등장 | 브루트·임프 동시 → 임프 `fromWave` 6, 또는 `introMinCount` 2 → 1 | 웨이브 4→5에서 총 체력이 2.1배로 급등한다. |
| 2 | 브루트 체력 | 160 → 120 | 웨이브 15에서 권총 8초가 걸려 콤보 유지 시간(2초)을 크게 넘는다. |
| 3 | 최소 스폰 간격 | 180ms → 300ms | 후반 웨이브는 몬스터가 짧은 시간에 몰려 나온다. |
| 4 | 몬스터끼리 밀어내는 세기 | 0.35 → 0.6 | 수십 마리가 몰리면 많이 겹쳐 보인다. |
| 5 | 웨이브 체력 증가 | 웨이브당 +8% → +6% | 무기 레벨업(피해 최대 +32%)으로 후반 화력이 늘었다. |

바꾸는 위치는 모두 `src/config/`이다. 플레이 감각에 따라 다시 검토한다.
